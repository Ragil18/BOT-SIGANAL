# TradeSignal Pro - Quick Start Guide

## Running the Application

### Step 1: Activate Virtual Environment
On Windows:
.\.verify_venv\Scripts\activate

On Mac/Linux:
source venv/bin/activate

### Step 2: Install Dependencies (if not already installed)
pip install -r requirements.txt

### Step 3: Run the High-Speed Web App
python webapp/server.py
# or using uvicorn directly:
uvicorn webapp.server:app --reload --port 8080

### Step 4: Open in Browser
Visit http://localhost:8080 to access the 60 FPS Quant Trading Terminal.
